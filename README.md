# 🚦 SafeCityAI - Traffic Violation Detection System

## 📌 Overview
SafeCityAI is an AI-powered traffic monitoring system that detects violations like **No Helmet** in real-time using Computer Vision.

This project uses **YOLOv5** for object detection and a **Flask API** for deployment.

---

## 🎯 Features
- 🚴 Helmet / No Helmet Detection
- 🎥 Real-time Webcam Detection
- 🟥 Red box for violations
- 🟩 Green box for safe riders
- 🔊 Sound alert on violation
- 📊 CSV logging support
- 🌐 REST API (Flask)

---

## 🧠 Technologies Used
- Python
- PyTorch
- OpenCV
- YOLOv5
- Flask
